## 게임 소개

**Avoid Them**은 그리드 위에서 펼쳐지는 2D 탄막 회피 게임입니다.
자유롭게 도망칠 수 없습니다. 오직 **칸 단위 이동**만으로, 사방에서 쏟아지는 탄막 사이를 계산하며 살아남아야 합니다.

한 번의 이동이 곧 생존과 죽음을 가릅니다.
벽에 몰렸다고요? 벽을 넘으면 **반대편으로 순간이동**합니다. 궁지가 곧 반격의 기회가 됩니다.

---

## 주요 특징

🎯 **그리드 회피** — 픽셀이 아닌 '칸'으로 피한다. 순간의 판단이 전부.

🌀 **벽 텔레포트** — 화면 끝은 막다른 길이 아니다. 반대편으로 넘어가 위기를 돌파하라.

📈 **성장하는 생존력** — 죽을수록 강해진다. 쌓은 포인트로 능력을 업그레이드하고 더 깊이 살아남아라.

🔥 **밀려오는 패턴** — 갈수록 촘촘해지는 탄막. 당신의 한계를 시험한다.
